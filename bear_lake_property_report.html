3 — Risks and Concerns ⚠️
🏚️
Mobile home condition is completely unknown High

The listing says it "may need to be removed." Without an inspection you are buying blind. Pre-1976 units have no safety code compliance; pre-1989 structures commonly contain asbestos. Must inspect before purchasing.

☣️
Asbestos abatement could spike demolition cost High

Michigan law requires an asbestos survey before demolition of any pre-1989 structure. Professional abatement: $2,000–$8,000+. The mobile home's age has not been confirmed.

💧
Well and septic status unknown High

The listing mentions neither. Scenarios: functional systems (inspect, ~$800–$1,500) → fine. Failed septic: $7,000–$35,000. Failed well: $8,000–$15,000. Soil that won't perc → engineered mound system: $15,000–$35,000+.

🌿
Possible wetlands could block all construction Medium-High

Pleasanton Township has a Wetland Overlay District. Manistee County has extensive mapped wetlands. If any part of this lot is regulated wetland, Michigan EGLE Part 303 permits are required before any digging — and can be denied. Check the free state wetlands map before closing.

📋
Zoning may restrict replacement structure Medium

Pleasanton Township has RA-1, RA-2, and RA-3 sub-districts with different rules. A new manufactured home may require special approval depending on sub-district. Tiny homes on wheels almost certainly not permitted.

❄️
100–125 inches of annual snowfall Medium

Lake-effect snow from Lake Michigan (5 miles west). Foundations must go 42 inches deep per Michigan code. Heating, plowing, and winterization are real recurring costs.

🌊
FEMA flood zone not yet confirmed Low-Medium

"Rolling hills" description is encouraging, but the specific FEMA designation has not been verified. If in a flood zone, insurance adds $800–$3,000/year. Run the free online check — takes 2 minutes.

    Check the FEMA flood map — free

  4. 4
    Call Manistee County Planning: (231) 929-5000

    Ask: "Can I put a new manufactured home on a permanent foundation at 14638 Pleasanton Hwy after removing the existing mobile home?" Get it in writing.

  5. 5
    Look up the property taxes online

    Go to: maps.liaa.org/manisteeparcels/propertysearch.asp · Search parcel 26101-1202140002. Shows assessed value and annual tax bill. Also try: bsaonline.com/?uid=2022

  6. 6
    Ask seller for well and septic records

    Request any prior inspection records, well drilling logs, and septic permits. If none, make a well water test and septic inspection a written purchase contingency.

10 — Automation Script (Python) 🐍

The companion file bear_lake_scraper.py automates the data-retrievable checks. Install dependencies and run: 

pip install requests beautifulsoup4 lxml
pip install selenium undetected-chromedriver   # optional Selenium fallback

python bear_lake_scraper.py

What it checks automatically:

✔US Census Geocoder — exact lat/lon (free, no API key)
✔FEMA NFHL REST API (layer 28) — flood zone + SFHA flag
✔USFWS NWI MapServer — wetland features within 100m of parcel
⚠BS&A Online — tax records (requests attempt + Selenium fallback)
⚠LIAA parcel portal — owner, acreage, legal description
📄Outputs bear_lake_data.json with all results
Why BS&A and LIAA may block automated requests: Both portals use ASP.NET session tokens and some JavaScript rendering. The script tries direct POST first; if blocked, it falls back to undetected-chromedriver Selenium. If both fail, the script prints the direct manual URL. For production use, consider Regrid API, ATTOM Data, or PropStream (paid, but clean REST APIs with no scraping needed).
